# Demo Mode

## Why Demo Mode Exists
Demo mode provides a safe, deterministic layer of fallback data for presentations. If the backend is unavailable or lacks sufficient data, the application will use the local `demoData.json` to populate the frontend, ensuring the application always looks fully featured and heavily populated for demonstrations.

## Configuration
The mode is toggled using the environment variable in the `client/.env` file:
`VITE_DEMO_MODE=true`

To disable and run in full production (real API only) mode, set it to:
`VITE_DEMO_MODE=false`

## Demo Data Location
The structured demo data is located at:
`client/src/demo/demoData.json`

The fallback logic intercepting API failures is located at:
`client/src/demo/demoDataService.ts` and `client/src/lib/api.ts`.

## How It Works
When `VITE_DEMO_MODE=true`, the Axios API interceptor monitors responses. If a response fails or returns empty data (e.g., 0 activities), the interceptor seamlessly intercepts it and resolves the promise using the mock data generated by `demoDataService.ts`. Authentication always uses the real API backend.
